# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept feedback gracefully, and do not harass or discriminate. Maintainers may remove comments, commits, or contributions that violate this, and may ban repeat offenders.

Report conduct issues privately through GitHub's **Security → Report a vulnerability** form on this repository, or via the maintainer's GitHub profile contact.
