Halaman Complaint bisa dibuka user tanpa hak akses via URL langsung

StatusIn progress
SeverityHigh
PriorityNormal
ModulAccess Control
Penanggung jawabVendor Dev
Dilaporkan olehTim QA, [TGL]
Lingkungan[VERSI] · [BROWSER]
Halaman/dashboard/complaint

Deskripsi

User tanpa hak akses ke modul Complaint tetap bisa membuka halamannya jika mengetik URL langsung. Menu sudah disembunyikan, tetapi halaman tidak memeriksa peran.

Langkah reproduksi

  1. Login sebagai user tanpa hak akses Complaint.
  2. Buka URL /dashboard/complaint.
  3. Halaman terbuka dan menampilkan daftar complaint.

Hasil aktual

Halaman terbuka dan menampilkan daftar complaint.

Hasil yang diharapkan

Diarahkan ke halaman 403 karena user tidak punya hak akses.
