08-projects-CRM

Urutan Aktual lalu Diharapkan. Penanda wajib pada label. Saran bug mirip muncul di samping saat judul diketik. Bukti naik di atas lingkungan teknis yang dilipat.
5. Laporan kesiapan rilis
10-projects-CRM-reports
Ide terbaik di aplikasi ini: verdict BLOCKED dengan daftar penghalang. Tetapi verdict hanya sebesar kartu lain, dan bar severity hanya dibedakan lewat hue.
Verdict jadi hero dengan angka penghalang. Bar bernilai dan meter bentuk. Setiap ID bisa diklik. Ada tombol salin ringkasan untuk dibagikan.
6. Notifikasi
05-notifications

Kelompokkan per jenis dengan jumlah. Aksi Setujui atau Tolak langsung di baris. Titik hanya untuk yang belum dibaca.

Pecah menjadi tab: Umum, Modul, Agent dan API key, Kuota. Urutan modul lewat seret, bukan tombol.
